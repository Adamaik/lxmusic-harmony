## 二、桌面歌词：为什么「位置每次开关会重置」改不了

桌面歌词不是本应用自绘的窗口，而是**系统的歌词悬浮窗**：应用侧只有

```
avSession.isDesktopLyricSupported()
session.enableDesktopLyric(enable)
session.setDesktopLyricVisible(visible)
session.isDesktopLyricEnabled() / isDesktopLyricVisible()
session.setDesktopLyricState({ isLocked })   // DesktopLyricState 只有 isLocked 一个字段
```

（`@ohos.multimedia.avsession.d.ts`，API 23）。**没有任何读取/设置窗口位置的接口**，
所以应用既拿不到「用户上次把歌词拖到了哪里」，也没法在重新显示时恢复它。

现有实现已经做了能做到的最小化：
- 组件在会话创建时只 `enableDesktopLyric(true)` 一次；
- 平时只用 `setDesktopLyricVisible()` 显隐，暂停不收起（避免一显一隐地闪）；
- 只有「停播 / 换到没有词的歌 / 用户关掉开关」才隐藏。

但 `visible=false` 时系统会销毁那个悬浮窗，下次显示按系统默认位置摆放 —— 位置重置是系统行为。
若一定要记住位置，只能放弃系统歌词、自己做一个悬浮窗（需要悬浮窗权限、还要自己做滚动渲染与手势），
代价远大于收益，除非以后有其它理由要自绘歌词，否则不建议做。

「加描边」同理：文字由系统渲染，应用只能给 LRC 文本，控制不了字体、颜色、描边。
