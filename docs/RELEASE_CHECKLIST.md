| 权限 | 用途 | 声明状态 | 审核要求 |
|---|---|---|---|
| `ohos.permission.INTERNET` | 在线搜索/播放/同步 | ✅ 已声明，带 `reason_internet` 与 usedScene | 通过 |
| `ohos.permission.KEEP_BACKGROUND_RUNNING` | 后台/息屏继续播放（配合 `backgroundModes: audioPlayback`） | ✅ 已声明 | 通过（属正常音频类权限） |
| `ohos.permission.MICROPHONE` | 听歌识曲「周围声音」 | ✅ 已声明，带 `reason_microphone` | **审核会重点看**：必须在隐私声明里写清「仅在用户主动进入识歌并选择环境音时采集，不后台录音、不上传原始音频」，否则容易被拒 |
| `ohos.permission.FILE_ACCESS_PERSIST` | 本地音乐「引用式导入」 | ❌ **故意未声明**（代码已实现，权限一开就会卡上架检测的 ACL 一致性） | 需要在 AGC 申请受限 ACL，批准后用带 `allowed-acls` 的 release Profile 再加回；当前自动退回「复制进沙箱」，功能不坏 |

## 五、内容与版权风险（这一项最可能卡审核）

| 风险 | 说明 | 建议 |
|---|---|---|
| **第三方音源脚本** | 应用本身不提供音乐内容，但支持导入「洛雪自定义源」脚本，脚本由第三方提供、可解析各平台播放地址 | 隐私政策与关于页要明确「音源由用户自行导入，应用不内置、不分发任何音源」；**不要把音源脚本打包进安装包**（当前未打包，`rawfile` 里只有 `lx-runtime` 运行时代码） |
| **音乐版权** | 聚合播放第三方平台内容，版权归属各平台 | 上架填写「本应用不存储、不分发音频内容，仅作为用户本地/自建音源的播放器」；准备好被要求提供资质时的说明 |
| **评论区** | 展示第三方平台评论（只读、不发布） | 已实现「评论来自X · 仅供浏览」提示卡，符合「注明来源 + 不提供发布」的口径 |
| **参考了 GPL 项目的行为** | 播放页动效/评论区的**信息结构与交互**参考 LxMine（GPL-3.0），代码为本项目自行实现、未复制其源码或资源 | 当前无 GPL 代码引入；**若日后直接搬其 WebView 舞台资源，必须处理许可证**（整体转 GPL 或取得授权） |
| 应用内跳转外部网页 | 仓库地址、AppTest 安装、书源登录等 | 需在隐私/关于页说明外链行为 |

## 六、上架前自检（AGC 上传后系统会跑）

- [ ] 包名非 `com.example.*`，vendor 非 `example`
- [ ] release 包用**发布证书**签名，且与 AGC 登记的证书一致
- [ ] 「软件包管理 → ACL 权限声明一致性」无红叉（当前未声明 `FILE_ACCESS_PERSIST` 即为过此项）
- [ ] 隐私政策 URL 已填、可访问
- [ ] 权限用途文案与隐私政策一致
- [ ] 图标/名称/截图（手机 + 平板两套，本应用声明了 `deviceTypes: phone, tablet`）
- [ ] 内容分级问卷
- [ ] 版本说明（可直接复用「更新公告」第七版文案）
- [ ] 首次启动无崩溃、无强制登录、无诱导跳转

## 七、发布前技术回归（与上架无关但会翻车）

- [ ] 换包名后：本地数据清空 → 引导页/首启体验要能自解释（导入音源、扫描本地音乐、可选同步）
- [ ] 没有音源时：所有页面不崩、提示「先去设置导入音源」
- [ ] 断网启动：不卡死、不反复弹错
- [ ] 后台播放 30 分钟：不被系统冻结（`KEEP_BACKGROUND_RUNNING` + `audioPlayback` 长时任务）
- [ ] 平板/折叠屏：宽屏布局（本应用已做 `WidePane`/`cardWidthOf`）
- [ ] 低版本 API 设备（若 `compatibleSdkVersion` 低于 targetSdkVersion）：HDS/粒子/取色缺失时的降级已实现，需实测一台
