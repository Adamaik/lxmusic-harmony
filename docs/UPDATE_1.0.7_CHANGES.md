## 一、改动点（13 个文件）

### 1. 歌单详情页搜索（P1，用户已催过）
- `views/PlaylistDetailView.ets`
- 新增 `allSongs`（全量，非 @State）+ `@State songs`（当前显示集），头部加放大镜圆钮，展开搜索条。
- 过滤口径：歌名 + 歌手，`trim + toLowerCase` 包含匹配，顺 `allSongs` 遍历保持原排序。
- **作用域语义**：搜索后「播放全部 / 全选 / 下载全部」全部只作用于筛出的歌，文案同步变「播放筛选结果」「筛选出的 N 首」。
- 进多选先清过滤；多选态不画放大镜；无结果有专门空态 + 「清除搜索」。

### 2. 引擎日志看全文（P1，已答应用户）
- 根因：`core/source/SourceEngine.ets:884` 把日志裁到 200 字符后入库，原文没留。
- `core/source/LxTypes.ets`：`SourceLog` 增可选 `full`（完整原文），`message` 仍是面板那一行。
- `core/source/SourceEngine.ets`：`describeResponse()` 改为返回 `{summary, full}`；`pushLog()` 追加第 4 个可选参数（既有 ~30 处调用点零改动）；HTTP 响应与脚本返回体两处传全文。
- `views/SourceSettingsView.ets`：日志行可点 → `bindSheet` 弹「日志详情」；卡片标题行加「复制全部」；底部一行弱提示。
- 新增 `views/LogDetailView.ets`：全文可滚动、可长按选中、「复制全文」、显示完整日期与字符数（让用户能判断是否还被裁）。

### 3. 起播耗时埋点（P0-1 的诊断前置，不改播放行为）
- 新增 `core/player/StartupTiming.ets`（单例计时，带 20s 看门狗、切歌残值补打）。
- `core/player/PlaySession.ets`：`begin()` 在取地址前；`beginBuffer()` 在送进播放器前；失败路径补 `markFailed`。
- `core/player/LxPlayer.ets`：`playUrl` 挂看门狗、`playing` 结算、两处 `error` 报失败。
- 日志：`起播耗时 resolve=1234ms buffer=567ms 源=tx 音质=320k 命中缓存=false 曲目=晴天 结果=成功`
- 排查：`hdc shell hilog | grep 起播耗时`

### 4. 平台源失败自动换源（P0-2）
- `core/player/PlaySession.ets`：新增 `switchSourceAndResolve()`（唯一入口），仅在**平台源取地址最终失败**（含拓展音质降档后仍失败）时触发。
- 备选顺序 `wy → kw → kg`，候选必须：该平台声明了 `musicUrl`、有内置搜索、**规范化后歌名与歌手集合都相等**（去空白、去尾部括号组、歌手排序），否则放弃。
- 先解析成功才写回 `item`（失败不留脏身份）；只换一次不递归；换不成仍抛**原错误文案**；成功 toast「QQ 音乐源不可用，已自动换源播放」并重算 `cacheKey`。
- 本地音乐 / WebDAV / 听书在更早分支返回，永不进入。

### 5. 榜单多选可发现性（P1）

### 6. 版本与文案（P2-6 + 收口）

## 二、测试清单（建议按序）

### A. 安装与版本
1. 用 `entry-default-signed.hap` 覆盖安装（版本号已 +1，可直接覆盖 1.0.6）。
2. 「设置 → 关于」版本显示 **1.0.7**；「更新公告」第一条是**第七版**，日期 2026-11-16。

### B. 歌单搜索（重点）
3. 打开几百首的自建歌单 → 头部右侧放大镜；点开 → 搜索条 + 输入框可起键盘。
4. 输入歌名片段 → 实时收敛、计数与「筛选出 N 首」一致；**连续输入时键盘不收起、光标不掉**（唯一静态无法确认点）。

6. 筛选态点「播放筛选结果」→ 队列恰为筛出那几首；点单行从该首播。
7. 筛选态长按进多选 → 搜索条自动收起、恢复全量；全选/加歌单/删除正常；退出多选滚动位置正常。

### C. 引擎日志全文
8. 加载音源后搜一首歌 → 日志应有 `音源请求响应：HTTP 200, body(N)=…`（面板仍是裁剪版、以 `…` 结尾）。
9. 点该行 → 半模态「日志详情」显示完整内容，底部「共 N 字符」与 `body(N)` **一致**；可滚动。

### D. 起播耗时与换源
12. 冷启动点在线歌 → `hdc shell hilog | grep 起播耗时` 出现一条 `命中缓存=false`，看 resolve 与 buffer 哪个大（**这是"在线听很久才出声"的定位数据，请把这条日志发我**）。

14. 找一首 QQ 源 + 其它平台也有的热门同名曲，若 tx 取不到地址 → 出现 `换源tx->wy` + toast，且**听到的是同一首**。

16. 换源成功后：红心收藏→退出重进仍在且能播；开「缓存时自动下载」再播，下载管理正常出现。
17. 回归：本地音乐 / WebDAV / 听书各播一首，无换源备注、行为与改前一致；飞行模式点在线歌，错误文案与改前逐字一致。
